Accessibility

Our Commitment

Roy Can Help aims to meet WCAG 2.2 Level AA accessibility standards. We believe that information should be available to everyone, regardless of ability.

What We Have Done

This site includes the following accessibility features:

  • A skip link at the top of every page to jump directly to the main content.
  • Keyboard navigation support. You can navigate through the entire site using the Tab and Enter keys, with visible focus indicators on all interactive elements.
  • Form controls are labeled with descriptive text.
  • Proper heading hierarchy (h1, h2, h3) to provide structure for screen readers.
  • Color contrast checked against WCAG AA standards in both light and dark modes.
  • Responsive design that works on phones, tablets, and desktop screens.
  • Text that reflows without horizontal scrolling at any zoom level.
  • Respect for the prefers-reduced-motion setting. The site does not use unnecessary animations for people who have asked for reduced motion.
  • Support for light and dark mode based on system preferences.

Testing and Known Limitations

Testing for accessibility is ongoing and imperfect. If you find an accessibility problem that we have not addressed, please report it through the Contact and Corrections page. Include a description of the problem and how you encounter it.

We will make a good-faith effort to fix accessibility issues. Fixes may not be immediate, but accessibility problems are taken seriously.

Reporting Accessibility Issues

If you encounter any accessibility barriers on this site, please report them through the Contact and Corrections page. Tell us what the problem is and how you use the site. Your report helps us make the site better for everyone.
